# Bignumbermultiplier
A Java program capable of multiplying extremely big integers that exceeds limits of standard data types.

## Features
- Multiplies integers containing tens of thousands of digits
- Handles numbers far beyond the range of `int` and `long`
- Implemented entirely in Java
- Originally developed independently in 2016
